# v0.16.2 Goal ETA UX

- Home now shows estimated remaining study days for all three goals:
  - A 60 points
  - B 70 points
  - C 75 points
- Estimates use the existing A / A+B / A+B+C inclusion logic.
- Default daily capacity is the same as the Today plan: max 10 required tasks/day.
- Estimates react to learning history:
  - unseen: 1 learning unit
  - attempted/exposed/guided: 2 units (repair + reinforcement)
  - reproduced: 1 unit
  - independent/consolidated: 0 units, or 1 refresher unit after 7 days
  - a newer exam re-error reopens the item with 2 units
  - a newer independent exam correct response removes mandatory units at that point
- Initial empty-history reference values from the current 160-question classification:
  - A 60: 88 questions, ~18 days
  - B 70: 143 questions, ~29 days
  - C 75: 160 questions, ~32 days
- The UI explicitly states that these are workload estimates, not guaranteed days to achieve the target score.
- No data schema change was required; dataVersion remains 5.
- Existing learning history is preserved.
