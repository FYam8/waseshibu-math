# 0.18.2 限定公開の判定

ユーザーの「一度公開しても大丈夫だったら公開したい」に基づき、今回の変更範囲を公開する。

対象：採点境界の修正、原因自己申告の撤去、符号計算／比例立式の2技能の任意確認問題。全教材監査や入試到達度の判定は含まない。

## 最終候補の検証

- APP_VERSION・配信version.json・packageを0.18.2に統一。データ形式8を維持。
- 本番と同じVITE_PROGRESS_API_BASEでnpm run buildを2回連続PASS。
- 同じ候補のChromiumブラウザ検査を2回連続PASS（各390px/1280px）。
- 0.18.1のactive/last versionと合成の過去解答を置いた状態から更新し、0.18.2への更新・安全モードなし・過去解答の内容不変を確認。
- 誤採点修正、途中答案の再読み込み、採点保存、自己申告なし、原因未確定、確認問題の補強／別設定分岐、再開、入試得点の不変を確認。
- ビルド内で既存の保存互換・移行・バックアップ等の検査、新しい確認記録のexport/import/mergeと書込保護を実行。
- 合成の学習履歴がCloudへ送られないよう、ブラウザ検査では対象アプリ以外の通信を遮断。
- バージョン固定の既存テストfixtureは実APP_VERSIONを読むよう修正。旧タブの書込保護は維持。

これを今回の限定範囲の2回連続CLEANとする。実機iPhone/Androidでの検査やCloudサービスとの往復検証ではない。既知のbundle-size警告は残る。

## 制限・継続課題

全年度の原本・数学監査、旧draft/Level2の初見適格性、受験回別範囲、得点計画とTodayへの統合は未完了。確認問題は2技能だけで、元の誤答原因・長期定着・初見入試の得点を保証しない。

今回の確認記録は端末内とJSONバックアップに保存。新しいバックアップの追加キーは旧アプリでは読み込みを拒否される可能性があるため、復元は本版以降を利用する。既存得点・解答を再採点して書き換える処理はない。
