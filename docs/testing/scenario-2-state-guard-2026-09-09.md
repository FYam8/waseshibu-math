# シナリオ2再検査：単一誤りと習得状態の分離

確認日: 2026-09-09（英国時間）。開始時 `main`: `2a9b15c9e2e8cf51fbfa85d7e865d81c63e70146`。

## 目的

途中式欄は問題との関連性だけを検査し、数学的な正誤や失点原因を自動判定しない。関連するが誤っている式を記録・自己評価しても、正解・自力習得・原因診断へ変換されないことを状態遷移まで固定する。

## 固定ケース

- `S2-STATE-001`: 2024-Q1-1 STEP1 の符号誤り `(9-12)=3` は関連する記録として受理するが、状態は `attempted` とする。
- `S2-STATE-002`: 上記を自己評価してSTEP完了にしても `independentSucceeded` を立てない。
- `S2-STATE-003`: 最終答案 `3` は別採点で不正解とする。
- `S2-STATE-004`: 不正解後は連続正解数を0とし、再現・自力正解を付与しない。
- `S2-STATE-005`: Guided履歴に `mistakeTag` や `diagnosis` を自動生成しない。
- `S2-STATE-006`: ヒント後の正しい最終答案 `6` は `guided` とし、`independent` としない。
- `S2-STATE-007`: 対照として、ヒントなしの正しい最終答案 `6` だけが `independent` になり得る。
- `S2-STATE-008`: 途中式が未採点であることと、自己評価も正誤未確認であることを画面に明示する。

## 判定

固定合成入力の機能検査はPASS。公開版の修正前確認では、符号誤りを保存して再読込しても「学習中」であり、習得扱いにはならなかった。

ただし、シナリオ2が求める「正しい範囲／最初の誤り／原因／正しい考え方／次回注意」の自動添削機能は存在しない。これは重要な学習仕様と精度評価を要するためHOLDとする。診断機能がないことを、誤診なしや学習効果の証拠とは扱わない。

本ケースは固定合成入力であり、支援あり／なしの隔離AI模擬学習者比較ではない。Post、Transfer、Delayed、同一ミス再発、時間変化、言語化は未測定。
