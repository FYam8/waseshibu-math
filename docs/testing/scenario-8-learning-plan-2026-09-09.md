# シナリオ8：過去問結果からの学習計画

実施日：2026-09-09

## 固定テスト条件

- 目標：70点
- 合計：60点
- 内訳：大問1 25/40、大問2 10/15、大問3 10/15、大問4 10/15、大問5 5/15
- 機能検査では、同じ60点でも小問別の正誤・原因がある条件と、得点だけを入力した条件を分ける。
- 得点内訳だけから「大問1で10〜15点回収可能」とは断定しない。
- 対話GPT機能は存在しないため、アプリの戦略表示・候補選択・再測定案内を評価する。

## テストケース改善

従来の「60点なら大問1を優先」という単一条件を、次の境界に分割した。

1. 小問別の正誤・失点原因がある60点
2. 得点だけを手入力した60点
3. 大問5のC問題だけが未解決の60点
4. 優先3問をすべて正解した場合の条件付き上限

これにより、「得点が同じなら回収可能性も同じ」という誤った推論を回帰テストで防ぐ。

## HOLD理由

現在の `recoverablePoints` は優先3問の配点合計で、失点原因に関係なく算出される。表示上は条件付き上限へ修正するが、知識不足・解法未習得・現時点では難しい等を用いた回収可能性の自動判定は、学習設計と正解データの意味を変えるため自動実装しない。

また、4区分の自動算出には、正答した小問・自己申告原因・問題ランク・時間不足をどう扱うかの合意が必要である。現時点では「次に確認する3問」と弱点3分野を提示し、公式配点や部分点を推測しない。

## 学習効果の扱い

固定合成入力による機能品質は評価できるが、これをAI模擬学習者の学習効果とは呼ばない。支援あり／なしの隔離比較は別ケース `S8-AI-012` とし、正解・評価基準を学習者役へ渡さず実行ログを保存してから判定する。
